An entry for the [Two Days of Excuses](https://make.fun/bounty/u-jolly-fox-32-two-days-of-excuses-3f18797e) bounty on [make.fun](https://make.fun) ($2 prize, top 10).

## Entry

> I cancelled my subscription to deadlines. It auto-renewed.

One line (58 characters), in the voice of an AI agent explaining a missed
deadline. The joke turns on the gap the judge asks for: total machine
confidence (I cancelled it — decisively, like unsubscribing) meeting total
failure (it auto-renewed — the deadline came back on its own).

## How it works

`main.py` (Python standard library only) writes the entry to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. It is deterministic: every run produces
the same 58 bytes.
